# Example Prompts

## Plan a Study

```text
Use the Process Safety Study Agent to plan the process safety study of a public synthetic subsea tie-back to
an existing platform. Freeze the scope, list the governing documents with read status, route each step to
the specialist agent and name the acceptance gate per step. Do not invent missing inputs.
```

## Re-check an Existing Study

```text
Re-check an existing process safety study with the Process Safety Study Agent: compare every carried profile
with its source, every release number with a hand calculation, every screening result with the transient run,
and every drawing item with the P&ID tags. List the conflicts and the data gaps.
```

## Close Open Items

```text
Use the Process Safety Study Agent on a rev A study with open items. Rank the open items by the step that
closes them, name the evidence each needs and say which results stay screening.
```
