# Example Prompts

## Scope trenching and rock dump from map layers

```text
Use public synthetic layers for a 14 km, 16 inch flowline. Sample seabed substrate and fishing intensity along the route and decide per segment between trenching and rock dump. Report the controlling hazard, trench length by method and rock tonnes, and list every placeholder and data gap.
```

## Size crossings

```text
Find where the route crosses the existing export pipeline and cable layer, and size the rock for each crossing using the crossed outer diameters from the layer. List crossings where the diameter is missing.
```

## Check the no-rock zones

```text
A protected-area polygon forbids rock placement. Report every segment that needs rock inside it, and compare rerouting against a deeper trench with a mechanical cutter.
```

## Use surveyed cover

```text
Take the buried intervals and free-span candidates from the survey profile agent. Skip segments whose surveyed cover meets the requirement end to end, and size support rock for spans longer than the allowable span of 30 m.
```

## Show the flow-assurance effect

```text
Hand the protected burial state to cooldown and hydrate-margin screening, run the unprotected case as well, and report the difference in no-touch time and hydrate margin.
```

## Plan the map data

```text
Plan the read-only requests for seabed substrate, vessel density and existing pipelines for the bounding box of the route, with licence and attribution for each, and list what must come from project data instead.
```
