# ncs-ownership-equity-agent

Finds who owns Norwegian Continental Shelf fields, discoveries and licences from
the open Sodir DataService and turns it into net-equity inputs for field
evaluation and economics. Prospect equity is not public: it is user-supplied or a
labelled licence proxy.
