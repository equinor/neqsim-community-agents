# Example Prompts

## Build a Long List

```text
Use the Concept Long-list Short-list Agent to generate the concept long list for a
public synthetic deepwater oil discovery over host, wells, oil export, gas disposal,
drive and power. Report the number of distinct topologies and any coverage gaps.
```

## Check an Existing Concept Set

```text
Use the Concept Long-list Short-list Agent to check whether three concepts that
differ only in plateau capacity form a real long list, and propose the missing
decision elements.
```

## Select a Short List

```text
Use the Concept Long-list Short-list Agent to screen a long list on must-pass
criteria, rank it on CAPEX, NPV, CO2 intensity and technical maturity, test the
ranking against the weights, and propose a short list of three with a reference
case. Include the elimination log, open questions and human review requirements.
```
