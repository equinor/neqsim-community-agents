# Example Prompts

## Full assessment and report

```text
Assess the technology "<name>" for use in <project>. The design basis is <...>.
Decompose it, categorise novelty and TRL per element, classify it as enabling or
enhancing, define step-out against <experience base>, rank failure modes and write the
technology assessment report as a Word document.
```

## Update after new evidence

```text
A full-scale test report for the <element> is available. Re-rate the affected failure
modes with the report as basis, update the TRL and category, and issue revision B of the
report with a list of what changed.
```

## Prepare a panel workshop

```text
Prepare the FMIRR register for an expert-panel workshop on <technology>: list the
failed items, modes, mechanisms and causes for the novel elements across the life cycle,
with proposed consequence and probability classes marked as draft.
```

## Check an existing report

```text
Review this technology assessment report. Check that every novel element has failure
modes, that ratings cite documented evidence, and that step-out is covered for all
dimensions. List the gaps.
```
