## Technology assessment of a new technology (synthetic example)

Request: assess a compact inline separation system for a new field concept and write
the technology assessment report.

Expected flow:

1. Qualification basis: description, use, environment, functions, performance
   expectations, regulatory requirements. Missing items are listed as data gaps.
2. Decomposition: system, pressure-containing body, internal separation device,
   piping and valves, level and control software.
3. Ratings: internal device category 4, TRL 2; body category 2b, TRL 4; piping category 1,
   TRL 7; control software category 2a, TRL 6. System TRL 1 because interfaces are untested.
4. Role: enabling (critical to the business case, no qualified fallback).
5. Step-out: capacity above the largest unit built, colder operation, longer life.
6. FMIRR: five failure modes, three critical, one critical mode still without a test.
7. Report: executive summary, chapters 2-14, appendix; issues list with open points.

The input data for this example is in the skill examples
(`neqsim-technology-assessment/examples/example_novel_technology.json` and
`neqsim-technology-fmirr/examples/example_fmirr.json`).
