# Resource Classification Agent

Public screening agent for SODIR `RC0`-`RC9` project maturity and SPE-PRMS categories. It keeps maturity separate from quantity uncertainty and records evidence gaps rather than guessing a class.

## Human review

Every result requires human review by qualified subsurface and reporting personnel. This agent does not replace formal SPE-PRMS classification, SODIR reporting guidance, reserves assurance, or resource-booking approval.

See [AGENT.md](AGENT.md) for the full specification.
