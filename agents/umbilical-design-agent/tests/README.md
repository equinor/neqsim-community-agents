# Umbilical Design Agent Tests

This agent is validated by the repository structure and manifest tests in
[tests/test_repository_structure.py](../../../tests/test_repository_structure.py) and
[tests/test_agent_manifest_schema.py](../../../tests/test_agent_manifest_schema.py).

Those tests confirm:

- The required agent files exist (AGENT.md, agent.yaml, README.md, examples, prompts, tests).
- AGENT.md contains all required sections and the correct required-skills frontmatter.
- agent.yaml contains all required keys, the required skill, and `human_review_required: true`.
- The required community skill `neqsim-umbilical-design` resolves.

## Manual Validation Notes

- Example data is public and synthetic.
- The numbers in the example come from the skill fixture generated by NeqSim.
- The agent states every screening default and lists the open items.
- Qualified human review is required before any design or procurement decision.

## Run the Tests

```bash
python -m unittest discover -s tests -v
```
