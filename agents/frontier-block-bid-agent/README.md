# Frontier Block Bid Agent

Public screening coordinator that judges a bid on an exploration block under a production sharing contract. It builds a declared resource and fluid basis, compares a near-field tie-back with a stand-alone concept, and reports expected monetary value with the break-even offered profit-oil share.

## Status

Draft (version 0.1.0). Screening only.

## Required skills

- `neqsim-psc-bid-economics-screening`
- `neqsim-anp-open-data`
- `neqsim-brazil-presalt-analogue-basis`
- `neqsim-asset-value-npv-screening`

## Human review

This agent performs public, educational screening only. It does not replace the bid-round contract terms, validated NeqSim field-development and economics studies, or qualified commercial and technical review. Company thresholds, partner terms and host capacity belong in a governed enterprise layer.
