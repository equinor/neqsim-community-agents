# Example prompts

- Place a four-slot template for a thin oil rim of 8 km by 0.7 km, with the host 15 km to the north-east. Screen a grid of candidate positions against the existing export pipeline and the host safety zone, and show how the ranking changes with the step-out weight.
- Compare tying the new template into a nearby existing template with a direct tie-in to the host riser. List crossings, parallel runs and zone entries for both routes.
- A pipeline start-up head and a PLET must fit between two existing lines. Screen the clearance and crossing angles against the limits in the attached design basis.
- Which of these candidate drill-centre positions can reach the injector target at 3.7 km, given a reach-to-TVD limit of 1.3 from the well-planning basis?
