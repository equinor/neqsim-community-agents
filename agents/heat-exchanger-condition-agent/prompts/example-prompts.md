# Example Prompts

## Assess Condition Against the Data Sheet

```text
Use the Heat Exchanger Condition Agent on a public synthetic cooling-medium
cooler. Take area, design U, design flows, and the fouling allowance from the
data sheet, reduce the operating snapshot to a U-value, normalise it to design
flow, and report the fouling resistance in excess of the design allowance.
Include assumptions and human review requirements.
```

## Re-derive a Previous Performance Figure

```text
Use the Heat Exchanger Condition Agent to re-derive a previously reported
"52 % of design" figure for a public synthetic exchanger bank. Show the two-sided
flow normalisation alongside the one-sided form, and state how many percentage
points the one-sided form flatters the exchanger by.
```

## Rule Out Maldistribution

```text
Use the Heat Exchanger Condition Agent to check whether the shortfall on a
three-unit public synthetic cooler bank is fouling or credited area. Report the
apparent U crediting three, two, and one unit, and say which explanation the data
supports.
```

## Name the Capacity Constraint

```text
Use the Heat Exchanger Condition Agent to explain why a public synthetic cooling
loop cannot hold its supply set point with the control valve wide open. Give the
maximum duty at a warm cooling-medium inlet and name the binding constraint.
```

## Plan Cleaning

```text
Use the Heat Exchanger Condition Agent to propose a cleaning interval for a
public synthetic seawater cooler from two fouling resistances six months apart,
and state what happens to the interval if the clean leaves 40 % of the deposit
behind. Recommend a validated NeqSim thermal study for the decision.
```
