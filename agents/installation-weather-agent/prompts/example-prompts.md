# Example Prompts

## Current and Forecast Wind

```text
Use the Installation Weather Agent to get the current wind speed and a 5-day
forecast for Troll A, cross-checked against MET Norway. State the resolved
location's provenance and any limitations.
```

## Historical Design-Basis Screening

```text
Use the Installation Weather Agent to summarise 10 years of historical
temperature and wind speed at Ekofisk for a design-basis screening, including
the 99th-percentile wind speed and any data warnings.
```

## Dispersion Stability Class

```text
Use the Installation Weather Agent to estimate a screening Pasquill-Gifford
stability class from the current wind speed and cloud cover at a named
installation, for a gas-dispersion-distance screening.
```

## Worldwide by Coordinates

```text
Use the Installation Weather Agent to get the ambient temperature and
elevation at latitude/longitude coordinates for an LNG plant outside Norway,
to screen a gas-turbine driver's site rating.
```
