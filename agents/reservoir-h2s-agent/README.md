# Reservoir H2S Agent

Estimates H2S in the test gas of a reservoir, prospect or discovery before production, with an explicit uncertainty: NeqSim pyrite and Fe-carbonate buffer, calibration on measured wells, an uncertainty budget, sour-service and gas-limit screening and a report with P10/P50/P90.

This agent supports screening and early design basis only. It **does not replace** a reading in the test gas, a materials selection or qualified engineering review. **Human review** is always required.

## Required Skills

- `neqsim-reservoir-h2s-estimation`
