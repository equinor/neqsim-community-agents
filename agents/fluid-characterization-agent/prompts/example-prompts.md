# Example Prompts

## Split-Factor Characterization

```text
Use the Fluid Characterization Agent to split a C7+ plus fraction (plus-fraction
molar mass 220 g/mol, density 0.84) into 5 pseudocomponents with a gamma split
factor, and show the per-pseudocomponent mole fractions and molar masses.
```

## Calibrate the Factor Against Measured Data

```text
Use the Fluid Characterization Agent to calibrate the plus-fraction split factor
so a gas-condensate model reproduces a measured saturation pressure of 248 bara
(weight 2) and a stock-tank-oil density of 832 kg/m3 (weight 1). Report the
fitted factor and per-target residuals, and state an acceptable-match criterion.
```

## Generate Representative Fluids and Allocate

```text
Use the Fluid Characterization Agent to generate low/base/high representative
fluid cases from a common reference fluid by adjusting the split factor, then
blend three wells with molar rates 3200, 1500 and 900 into one field composition.
List assumptions and what needs qualified human review.
```
