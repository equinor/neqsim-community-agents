# Surrogate Study Agent

Builds a validated active-learning surrogate of a NeqSim flowsheet so a study
can run thousands of cases, or locate where a capacity or specification limit
binds, with tens of NeqSim runs. Backed by the
`neqsim-active-learning-surrogate` and `neqsim-uncertainty-quantification`
skills.

See [AGENT.md](AGENT.md) for the workflow, inputs, outputs and limitations.
