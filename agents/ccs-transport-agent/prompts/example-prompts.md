# Example Prompts

## Chain Screen

```text
Use the CCS Transport Agent on the public example chain. Report the binding
link, the lowest single-phase and water margins and where they occur, the
depressurisation end temperature and the bottom-hole pressure against
fracture.
```

## CO2 Specification

```text
Use the CCS Transport Agent to check whether raising nitrogen from 2 to
4 mol % and hydrogen from 0.5 to 1 mol % keeps the 80 km line single-phase
with a 10 bar margin at 4 C seabed and 90 bara arrival.
```

## Operating Window

```text
Use the CCS Transport Agent with the Surrogate Study Agent to map the inlet
pressure range (100-180 bara) over which the chain stays single-phase and the
bottom-hole pressure stays below fracture, for seabed 2-8 C.
```
