# Subsea Infrastructure Capacity Agent

Finds what existing subsea and host infrastructure can take a new tie-in or increase production: free slots, spare tees
and hubs, spare or reusable lines (including gas-lift, injection and MEG lines), with status, remaining life and
verification level, ranked against a new-build tie-back.

## Capabilities

- Build and validate a per-item inventory (in use / spare / abandoned / planned / unknown) from open data and user documents
- Show free slots and spare lines by verification tier - open data never makes anything "free"
- Rank reuse versus new-build on distance, capacity, hydraulics, flow-assurance compatibility, lifetime and cost class
- Report the lifetime action for each reused item (replace, refurbish, life-extend, monitor)
- Hand off to export-tie-in-concept, surf-layout-design, tie-in-screening and area-development work

Screening only; human review required.
