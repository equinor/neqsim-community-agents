# Example Prompts

## Adjudicate "the Disturbance Got Worse"

```text
Use the Control Authority Agent on a public synthetic cooling loop. For each of
the last four summers I have the disturbance standard deviation and the fraction
of the period with the cooling valve fully open. Say whether the disturbance grew
or the loop lost authority, and show the evidence for each. Include assumptions
and human review requirements.
```

## Quantify Lost Disturbance Rejection

```text
Use the Control Authority Agent to measure how much disturbance rejection a
public synthetic loop has lost. Split the controlled variable by regime, report
the variance ratio between the saturated and modulating periods, and fit the
disturbance-to-process gain separately in each.
```

## Rule Out a Suspected Disturbance on the Numbers

```text
Use the Control Authority Agent to test whether a suspected external disturbance
explains the variability being complained about on a public synthetic loop.
Report the gain and the fit quality, and state what fraction of the variance the
disturbance actually accounts for.
```

## Convert a Trip Margin into Intervention Time

```text
Use the Control Authority Agent to say how long an operator has before a public
synthetic loop reaches its trip limit. Use the largest observed rate of change
and the current margin, and state the assumptions behind that number.
```

## Find What Consumed the Margin

```text
Use the Control Authority Agent on a public synthetic cooling loop whose valve is
saturated, then hand off: screen the cooler with the Heat Exchanger Condition
Agent and say whether exchanger degradation accounts for the lost authority.
Recommend a validated NeqSim study for the decision.
```
