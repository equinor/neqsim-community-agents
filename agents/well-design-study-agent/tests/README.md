# Well Design Study Agent Tests

Repository-level tests check that this agent includes the required files, metadata fields, documentation sections, examples and prompts.

The calculation tests live with the skill in `neqsim-community-skills` (`skills/subsurface/neqsim-well-design-study/tests`). They cover API TR 5C3 ratings against published values, collapse continuity, pipe weights, kick tolerance behaviour, window flags, seat proposal, casing selection, minimum curvature closure, torque-and-drag ordering, ECD, erosional and Turner velocities, offset calibration, Monte Carlo reproducibility and the end-to-end study.
