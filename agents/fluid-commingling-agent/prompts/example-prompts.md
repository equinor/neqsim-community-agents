# Example Prompts

## Tie-in Compatibility

```text
Use the Fluid Commingling Agent to check a public synthetic gas condensate
against an asphaltenic host oil. They meet at 200 bara and 80 C and the
condensate share is 20-40 mol %. The host's onset refractive index is 1.445.
Report the worst blend ratio for each check, the confirming laboratory tests,
assumptions and the human review required.
```

## Two Zones in One Well

```text
Use the Fluid Commingling Agent to screen commingling two reservoir zones in
one well at 150 bara and 95 C. Zone B has SARA 0.62/0.24/0.10/0.04 and no
measured onset. Include the water-water scale sweep for the two formation
waters and state that the asphaltene onset is a correlation estimate.
```

## Gas-Lift Gas Into Heavy Oil

```text
Use the Fluid Commingling Agent to screen lift gas injected into a heavy oil at
gas-to-oil molar ratios of 0-40 %. Report where the live-oil refractive index
drops below onset and at which pressure along the tubing that happens.
```

## Blend Onset Pressure from a Measured Host Onset

```text
Use the Fluid Commingling Agent with a calibrated asphaltene onset. The host
oil's onset is 150 bara at 80 C; assume asphaltene 1000 g/mol, 1.15 g/cm3.
Report the onset pressure of each blend with the condensate from 0 to 80 mol %
and the share at which it reaches the 200 bara commingling pressure.
```
