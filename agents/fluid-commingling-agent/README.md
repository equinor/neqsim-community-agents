# Fluid Commingling Agent

Screens two fluids that will be commingled for problems that only the mixture
has: asphaltene destabilisation by dilution, gas breakout on mixing, a blend
hydrate temperature above both fluids, separator-gas H2S/CO2, and water-water
scale. Backed by the NeqSim blend sweep in the
`neqsim-fluid-commingling-compatibility` skill.

See [AGENT.md](AGENT.md) for the workflow, inputs, outputs and limitations.
