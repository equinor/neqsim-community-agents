# Reservoir Mercury Agent

Estimates elemental mercury in the gas of a reservoir, prospect or discovery with an explicit uncertainty: statistical estimate from tested wells, analogue tests, NeqSim mineral limits and a report with P10/P50/P90, reasoning and data gaps.

This agent supports screening and early design basis only. It **does not replace** a gas sample from the reservoir, a process mercury study or qualified engineering review. **Human review** is always required.

## Required Skills

- `neqsim-reservoir-mercury-estimation`
